**Puoi definire due modelli Django: uno per le specie di orchidee e uno per le condizioni di coltivazione reali. Questo ti permetterà di incrociare dati meteorologici e fornire consigli personalizzati.**

---

## 🌸 Modello `OrchidSpecies`: caratteristiche ideali per ogni specie

Questo modello descrive le esigenze biologiche e ambientali della specie.

```python
class OrchidSpecies(models.Model):
    name = models.CharField(max_length=100)  # es. Phalaenopsis
    origin_zone = models.CharField(max_length=100, blank=True)  # es. Indonesia
    temperature_min = models.FloatField()  # es. 15.0
    temperature_max = models.FloatField()  # es. 26.0
    light_intensity = models.CharField(max_length=50)  # es. "media", "alta", "ombra"
    humidity_preference = models.CharField(max_length=50)  # es. "umido", "asciutto"
    prefers_mounting = models.BooleanField(default=False)  # coltivazione su zattera
    fertilization_frequency = models.CharField(max_length=50)  # es. "settimanale", "mensile"
    rest_period_start = models.CharField(max_length=20, blank=True)  # es. "novembre"
    rest_period_end = models.CharField(max_length=20, blank=True)  # es. "febbraio"
    rest_temperature_min = models.FloatField(null=True, blank=True)  # es. 7.0
    rest_temperature_max = models.FloatField(null=True, blank=True)  # es. 10.0
    notes = models.TextField(blank=True)

    def __str__(self):
        return self.name
```

## 🏡 Modello `CultivationCondition`: condizioni reali di coltivazione

Questo modello registra dove e come viene coltivata una pianta specifica.

```python
class CultivationCondition(models.Model):
    orchid = models.ForeignKey(OrchidSpecies, on_delete=models.CASCADE)
    location_type = models.CharField(max_length=50)  # es. "casa", "serra", "esterno"
    current_temperature = models.FloatField()
    current_humidity = models.FloatField()
    current_light = models.CharField(max_length=50)  # es. "sole pieno", "nuvoloso"
    wind_speed = models.FloatField()  # km/h
    forecast_rain_days = models.IntegerField(default=0)
    last_watered = models.DateField()
    notes = models.TextField(blank=True)

    def __str__(self):
        return f"{self.orchid.name} @ {self.location_type}"
```

## 🧠 Esempi di logica futura

Con questi modelli puoi scrivere funzioni tipo:

```python
def should_water(orchid, condition):
    if condition.forecast_rain_days > 2 or condition.current_humidity > 80:
        return "Non bagnare: aria già umida."
    if condition.wind_speed > 20:
        return "Attenzione: vento forte, proteggi la pianta."
    if condition.current_light == "nuvoloso":
        return "Non serve molta acqua oggi."
    return "Puoi annaffiare normalmente."
```

- Phalaenopsis: preferisce 18–26 °C, sotto i 15 °C rallenta, sotto i 10 °C rischia marciume.
- Cattleya: ideale tra 15–25 °C, tollera fino a 10 °C se asciutta, sopra i 25 °C va annaffiata più spesso.
- Dendrobium: alcune specie richiedono riposo asciutto tra novembre e febbraio a 7–10 °C, altre sono sempreverdi.

## 🧱 1. Installazione di Django e DRF

```bash
pip install django djangorestframework
```

Aggiungi `'rest_framework'` a `INSTALLED_APPS` nel tuo `settings.py`:

```python
INSTALLED_APPS = [
    ...
    'rest_framework',
    'library',  # tua app con i modelli OrchidSpecies e CultivationCondition
]
```

## 📦 2. Crea o aggiorna la tua app

Se non l’hai già:

```bash
python manage.py startapp library
```

## 🧬 3. Definisci i modelli (come già discusso)

Nel file `library/models.py` inserisci i modelli `OrchidSpecies` e `CultivationCondition`.

---

## 🧰 4. Crea i serializer

Nel file `library/serializers.py`:

```python
from rest_framework import serializers
from .models import OrchidSpecies, CultivationCondition

class OrchidSpeciesSerializer(serializers.ModelSerializer):
    class Meta:
        model = OrchidSpecies
        fields = '__all__'

class CultivationConditionSerializer(serializers.ModelSerializer):
    class Meta:
        model = CultivationCondition
        fields = '__all__'
```

---

## 🌐 5. Crea le view API

Nel file `library/views.py`:

```python
from rest_framework import viewsets
from .models import OrchidSpecies, CultivationCondition
from .serializers import OrchidSpeciesSerializer, CultivationConditionSerializer

class OrchidSpeciesViewSet(viewsets.ModelViewSet):
    queryset = OrchidSpecies.objects.all()
    serializer_class = OrchidSpeciesSerializer

class CultivationConditionViewSet(viewsets.ModelViewSet):
    queryset = CultivationCondition.objects.all()
    serializer_class = CultivationConditionSerializer
```

---

## 🛣️ 6. Configura le URL

Nel file `library/urls.py`:

```python
from django.urls import path, include
from rest_framework.routers import DefaultRouter
from .views import OrchidSpeciesViewSet, CultivationConditionViewSet

router = DefaultRouter()
router.register(r'orchids', OrchidSpeciesViewSet)
router.register(r'conditions', CultivationConditionViewSet)

urlpatterns = [
    path('', include(router.urls)),
]
```

E nel `urls.py` principale del progetto:

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('api/', include('library.urls')),
]
```
