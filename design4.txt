## 🧱 Fase 1: CBV per la base narrativa

### ✅ `ListView` per orchidee coltivate

```python
from django.views.generic import ListView
from .models import CultivatedOrchid

class CultivatedOrchidListView(ListView):
    model = CultivatedOrchid
    template_name = 'orchid_verse/orchid_list.html'
    context_object_name = 'orchids'
```

### ✅ `DetailView` per la scheda di una pianta

```python
from django.views.generic import DetailView

class CultivatedOrchidDetailView(DetailView):
    model = CultivatedOrchid
    template_name = 'orchid_verse/orchid_detail.html'
    context_object_name = 'orchid'
```

### ✅ `CreateView` per registrare un evento

```python
from django.views.generic.edit import CreateView
from .models import OrchidEvent

class OrchidEventCreateView(CreateView):
    model = OrchidEvent
    fields = ['orchid', 'date', 'event_type', 'description', 'photo']
    template_name = 'orchid_verse/event_form.html'
    success_url = '/orchids/'  # o redirect alla pianta
```

## 🌦️ Fase 2: Integrazione meteo e consigli dinamici

### 🔄 Strategia

- **App meteo esterna**: puoi interrogare un’API (es. OpenWeatherMap) per ottenere condizioni attuali e previste.
- **Modello `WeatherSnapshot`**: salva dati meteo rilevanti (temperatura, umidità, pioggia, ecc.).
- **Servizio di analisi**: confronta condizioni meteo con preferenze della specie (`temperature_range`, `humidity_preference`) e genera consigli.

### 🧠 Esempio di logica:

```python
def generate_care_advice(orchid, weather):
    if orchid.species.temperature_range == 'cool' and weather.temp > 25:
        return "Attenzione: la temperatura è troppo alta per questa specie."
    if orchid.species.humidity_preference == 'humid' and weather.humidity < 50:
        return "Consiglio: aumenta l'umidità ambientale."
    return "Condizioni favorevoli."
```

## ✅ Cosa significa “statica” vs “dinamica”

| Tipo di pagina | Contenuto | Esempi | Gestione |
|----------------|-----------|--------|----------|
| **Statica**    | Fisso, non cambia | “Chi siamo”, “Guida all’uso”, “Contatti” | `TemplateView` |
| **Dinamica**   | Dipende da dati o input | Lista orchidee, eventi, consigli meteo | `ListView`, `DetailView`, `CreateView`, ecc. |

---

## 🧩 Dove mettere la pagina statica nella tua app `orchid_verse`

### 📁 Struttura consigliata:

```
orchid_verse/
├── templates/
│   └── orchid_verse/
│       ├── home.html         ← pagina statica
│       ├── orchid_list.html  ← dinamica
│       ├── orchid_detail.html
│       └── event_form.html
```

### ✅ In `urls.py` della tua app:

```python
from django.urls import path
from django.views.generic import TemplateView
from .views import CultivatedOrchidListView, CultivatedOrchidDetailView

urlpatterns = [
    path('', TemplateView.as_view(template_name='orchid_verse/home.html'), name='home'),
    path('orchids/', CultivatedOrchidListView.as_view(), name='orchid_list'),
    path('orchids/<int:pk>/', CultivatedOrchidDetailView.as_view(), name='orchid_detail'),
]
```

---

## 🧠 Dove conviene mettere la pagina statica nel tuo caso?

Ti consiglio di usare la pagina statica come:

- **Homepage narrativa**: introduzione al tuo archivio botanico
- **Guida all’uso**: spiegazione di come registrare eventi, consultare consigli, ecc.
- **Sezione “Chi siamo”**: se vuoi raccontare il progetto o la tua collezione

📍 **Quindi: `home.html` dentro `templates/orchid_verse/` è perfetto.**
